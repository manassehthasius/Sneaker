# Material-Scans und Lichtumgebungen

Alle Scans stehen unter **CC0** (gemeinfrei): kostenlos, auch kommerziell nutzbar, ohne Namensnennung.
Die Farbtexturen wurden mit `tools/fetch_assets.py` in Graustufen umgewandelt, damit das Studio sie einfärben kann.

| Studio-Material | Quelle | Asset |
|---|---|---|
| Glattleder (`leather`) | Poly Haven | leather_white |
| Wildleder (`suede`) | Poly Haven | scuba_suede |
| Nubuk (`nubuck`) | ambientCG | Leather029 |
| Canvas (`canvas`) | ambientCG | Fabric061 |
| Strick (`knit`) | ambientCG | Fabric085 |
| Baumwolle, Schnürsenkel (`cotton`) | ambientCG | Fabric030 |
| Gummi (`rubber`) | ambientCG | Rubber004 |
| Mesh, Ripstop, EVA, Sohlenprofil (`tread`) | selbst erzeugt | `tools/fetch_assets.py` |
| Studiolicht (`/env/studio.hdr`) | Poly Haven | studio_small_09 |

- Poly Haven: https://polyhaven.com
- ambientCG: https://ambientcg.com
